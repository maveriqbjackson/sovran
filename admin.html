Integrity check

Re-downloads every deployed file, hashes it in this browser, and compares against the manifest committed to the repo. Any difference means a file changed without a commit.

This catches unauthorised code changes — a modified script, an injected tracker, a swapped page. It is not a bug detector and nobody should claim otherwise. What it does do is make silent tampering with the site itself very hard to get away with.

Build map snapshots

The Map loads from files on our own domain so visitors never make an outside request. This builds those files. Your browser queries OpenStreetMap, compacts the result, and hands you a file to drop into mapdata/ in the repo.

Overpass is a free service on donated hardware. Build a few states at a time, not fifty at once, and leave gaps between runs. Rebuilding every few months is plenty — the data changes slowly.
