SOVRAN map builder

Builds mapdata/<CODE>.json for every state you tick, one after another, by talking to OpenStreetMap directly from this browser. No server in the middle, so nothing can time it out, and the request comes from your own connection rather than a datacenter — which is the only reason OpenStreetMap tolerates it. Budget fifteen to twenty-five minutes per busy state and leave the tab open. It writes index.json for you at the end, so there is nothing to hand-edit.

This page cannot run from your hard drive

You opened it with file://. A page loaded straight off disk gets no origin, and the browser will not let it reach the internet — every request fails before it leaves your machine. That is a browser rule, not something this file can work around.

Put it on your own site and open it there: upload this file to the repo as builder.html, then go to https://mysovran.online/builder.html. Everything below will work from that address.

One request at a time, with a pause between them. If OpenStreetMap asks us to wait, we wait and try again rather than firing more requests at it — that is the thing the old version got wrong.

Drop the oversized <CODE>.json files in here and each is split into a small base file plus street tiles, then handed straight back. Nothing is fetched and nothing is uploaded — the file is read, split and saved inside this page, and nothing is thrown away. Pick several at once. Name them after the state (CA.json) so the tiles are named to match.
