SOVRAN map builder

Builds one state's mapdata/<CODE>.json by talking to OpenStreetMap directly from this browser. No server in the middle, so nothing can time it out. Expect five to twenty minutes for a busy state — leave the tab open.

This page cannot run from your hard drive

You opened it with file://. A page loaded straight off disk gets no origin, and the browser will not let it reach the internet — every request fails before it leaves your machine. That is a browser rule, not something this file can work around.

Put it on your own site and open it there: upload this file to the repo as builder.html, then go to https://mysovran.online/builder.html. Everything below will work from that address.
